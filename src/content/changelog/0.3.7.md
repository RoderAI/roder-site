## See what an action actually did

`browser_use` results lead with the action report and preserve it even when page state is long. Element listings include exact omission counts and an offset for continuation. Dead clicks, stale indexes and lost browsers report errors; clicking a native select explains the supported route instead of pretending it worked.

Chrome tool results also lead with outcomes and fit a line budget. Desktop gains `chrome_select`, while native computer results retain screenshots and report dialogs, new tabs and HTTP failures. Mac page actions send Command chords correctly.

## Stop before repeating a mistake

Jev retries unusable decisions and can then fall back to the frontier model. A low-confidence deletion on a similar row is not repeated. Loops stop with a named cause, and handoffs are represented as outcomes rather than failed tool calls. Webwright failures explain themselves and do not continue running past a timeout.

Models unable to receive tool-result images no longer see screenshot tools or claims that an unavailable screenshot was attached. A short selection hint helps the agent choose among multiple installed browser families. Existing browser setup remains usable; the improvement is in truthful feedback and bounded recovery.
