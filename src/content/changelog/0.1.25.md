## Codex behind the Roder interface

Roder can now select Codex as a complete agent backend. Its app-server translates thread, turn, streaming and approval operations to the Codex app-server, so the TUI and existing Roder clients can use Codex to run the agent loop. This is a separate choice from using Codex as an inference provider inside Roder's own runtime. Token usage from the Codex backend reaches Roder's turn counters.

## Pair Chrome once

The browser extension pairing now survives restarting Roder. The loopback port and owner-only token are saved in `<config-dir>/remote-pairing.json`, and the listener returns on startup. If the remembered port is occupied, Roder remembers a replacement port. Use `/remote regenerate` or `/remote unpair` to revoke paired browsers by rotating the token.

## Per-turn speed controls

API clients can set `service_tier_override` on a turn, including `priority` for OpenAI Fast mode. The choice applies to every inference round in that turn; usage records retain the tier OpenAI actually served. This release applies the field only to OpenAI requests. OpenRouter tier support arrives separately in 0.3.10.

The catalogs also gain GPT-6 Sol and Luna and refreshed GPT-6 and Claude entries. A worker-stack fix prevents the TUI from aborting on its first turn. Rust callers constructing `StartTurnRequest` directly must add the new optional field.
