## Use version probes in scripts

`roder --version` and `roder -V` now print the installed version before loading configuration or starting the terminal interface. Installation checks and scripts can inspect the binary without needing an interactive terminal or a working provider configuration.

This changes only the version-probe path. Normal CLI startup still loads your configuration and opens the interface as before.

See [installation](/docs/install/) for setup and update instructions.
