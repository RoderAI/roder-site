## Keep CLI release checks independent

Linux release verification now checks the ACP agent's CLI version. The app server has its own release version, so comparing that version against the CLI release could block CLI and npm publication even when the CLI build was correct.

This is a release-pipeline fix; it requires no configuration change. See [installation](/docs/install/) for available distribution methods and [ACP](/docs/acp/) for the client bridge.
