## Retain evidence through browser research

The distributed CLI now includes shared semantic browser observations, paginated document reads with context limits, retained source evidence and bounded navigation recovery. Research tasks can track an ordered requirements checklist and return readable findings through the configured fallback.

These changes help a research task keep its requirements and supporting evidence within bounded browser and model context. See [browser decisions](/docs/browser-decisions/) for backend configuration, observable outcome checks and fallback behavior.

## Keep the evaluation limits visible

Native Decisions research still has documented evaluation failures, including one forbidden-write false success. Full fallback remains the production policy. The smaller one-call rescue remains an evaluation-only experiment.

This release does not establish reliable native-only completion or remove the need to verify the observed result. Keep the existing approval and action boundaries in place; a driver's completion claim is not proof that the task succeeded.
