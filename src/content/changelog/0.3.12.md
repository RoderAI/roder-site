## Send the history Roder assembled

Responses requests are now sent as built. The former 15 MB client-side request budget and its removal of older tool images are gone, so the wire request no longer silently rewrites conversation history to fit a local byte ceiling. Keeping the prefix intact also preserves the provider's opportunity to reuse its prompt cache.

`RODER_RESPONSES_MAX_REQUEST_BYTES` no longer controls this behavior. Providers judge request size according to their own limits.

## Recover from the provider's actual limit

HTTP 413 becomes a typed `RequestTooLarge` error. OpenRouter's HTTP 400 maximum-context-length response becomes `ContextWindowExceeded`. The runtime uses these errors to trigger compaction rather than immediately abandoning the turn.

Recovery also recognizes the typed error when the response body is empty or has no familiar wording. Long conversations therefore have a better path forward without depending on a particular English error string. Provider limits still apply; this release changes how Roder preserves history and responds when those limits are reached.
