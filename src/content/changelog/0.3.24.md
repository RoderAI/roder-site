## Follow links without reading markdown syntax

The terminal transcript now renders assistant markdown links as their labels instead of showing raw `[label](url)` syntax. The destination remains clickable, so linked documentation and sources take less space without losing their target.

This is a transcript rendering change; it does not change the link the assistant supplied.

See the [terminal interface guide](/docs/tui/) for other transcript controls.
