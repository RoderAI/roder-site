## Switch the decision service

Set `JEV_DECISION_PROVIDER=openai` and supply an OpenAI API key to use Decisions for browser action selection. The agent continues to call `jev_browse` and the same-tab tools; Chrome sessions, action validation, approval policy and the optional irreversible-action gate remain shared with Jev. The text helper still supplies generated field values.

Decisions uses action-effect context and fresh viewport images to choose an operation and target. Text-only operation is available. Recognized secret input suppresses screenshots across calls, and text evidence is scrubbed for secret echoes. If optional capture fails, the client can continue with text evidence.

## Refusals and native integration

A refused question for an unused target does not cancel an otherwise valid action. Refusal of the required operation or chosen target stops execution, and safety checks stay closed when their answer is missing or invalid. Single-target questions are resolved locally because the endpoint requires multiple choices.

Embedding hosts can also ask Decisions to select among host-supplied native computer action batches. A blocked outcome and host-owned permissions remain part of that contract. Switching the decision backend does not itself grant desktop access or provision a Chrome session.
