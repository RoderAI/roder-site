## Keep OpenRouter conversations within context

The OpenRouter catalog now carries 25 routes with provider-reported context windows, image support and reasoning efforts. The refreshed set includes Kimi, Claude, GPT-6, Gemini, Grok, DeepSeek, Qwen, GLM, MiMo, Mistral and Muse routes. Runtime-discovered models expose reasoning controls when OpenRouter reports support.

OpenRouter accepting a `context_management` field does not mean it performs server-side compaction. Roder now compacts these conversations locally at 90% of the model window, including the Grok route that previously claimed native compaction. This avoids letting a long session run into a context limit under the wrong assumption.

## Launch from your configured shell

Inside tmux, Roder restarts its pane once for extended key reporting. That restart now retains the environment from the shell that launched Roder, including provider keys and values supplied by direnv or mise. You should no longer have to copy those values into the tmux server environment just to keep them after startup.

Version 0.3.9 further hardens how that environment is transferred; upgrade to that release or newer for the private-file handoff.
