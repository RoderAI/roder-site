## Compare values in aligned columns

Assistant markdown pipe tables now render as aligned grids with a header rule instead of raw `|` rows. Tables that fit the transcript width keep their columns aligned.

When a table is too wide, Roder falls back to labeled rows so wrapping does not crush neighboring columns together. You can read the same response in a narrow terminal without widening the window just to separate the values.

See the [terminal interface guide](/docs/tui/) for transcript rendering and navigation.
