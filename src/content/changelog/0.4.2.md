## Discover tools and skills from the first turn

CLI startup now builds the tool and skill discovery catalog instead of waiting for a discovery API request. Agents can use the catalog when they first need to find an available capability.

When the catalog is missing, discovery returns an actionable fallback. Agents skip redundant discovery searches or retries when discovery is unavailable, avoiding repeated attempts that cannot produce a result.

Catalog tools also use the same configuration-directory precedence as the catalog builder, so both look in the same configured location.

See [tool search](/docs/tool-search/) for catalog discovery and promotion.
