## Choose the current GPT models

The catalog now exposes `gpt-6.1-terra` with a 1M context window. Its published standard prices in this release are $1 per million input tokens, $0.05 per million cached input tokens and $5 per million output tokens.

The default GPT model is now `gpt-6.1-sol`. The older `gpt-6-sol` remains resolvable for existing configurations but no longer appears in selectors.

See [providers and models](/docs/providers/) for selection and configuration, and [usage analytics](/docs/usage-analytics/) for local reporting. Catalog prices describe this release rather than a guarantee of future provider pricing.
