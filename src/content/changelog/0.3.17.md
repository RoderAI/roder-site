## Keep Cursor work attached to the conversation

Cursor native and MCP tool calls now receive the results approved and executed through Roder's runtime. This repairs workflows where a Cursor turn needs to read files, make changes or use connected tools before deciding what to do next. Roder policy remains in control of tool execution.

Follow-up turns preserve thread context, so you can continue a task without losing the conversation that led to the next instruction. The fixes apply to the existing Cursor provider; there is no new authentication flow to configure.

## Pick models that the provider supports

Discovery and cached model lists remove retired Cursor model IDs, reducing failed selections caused by stale entries. The catalog refreshes Gemini 3.1 Pro and adds Gemini 4 Argon with its supported reasoning settings. Use the current model picker rather than relying on an old cached preview identifier.

See the [Cursor provider documentation](/docs/providers/#cursor-agentservice) for credentials and runtime routing.
