## Choose an image model for the task

Roder's OpenAI image provider now supports `gpt-image-2.5-flare` and `gpt-image-2.5-sunburst`. Flare is the default OpenAI image model across generation, editing, provider discovery and the TUI image command. Sunburst is available when you want the precision-oriented model for generation or edits.

```sh
roder media models --provider openai
roder media generate "a clean terminal product hero" --provider openai --model gpt-image-2.5-flare --size 1024x1024
```

Both models accept `auto`, `low`, `medium`, `high`, `xhigh` and `max` quality settings through the media request. Existing image artifacts can be used as editing inputs, keeping image creation and revision in the same Roder workflow. Older GPT Image models remain explicitly selectable; a saved older model selection is preserved.

## Configure API access before generating

This provider uses an OpenAI API key and separate API billing. Codex subscription sign-in does not authenticate the OpenAI media provider or verify a particular GPT Image 2.5 model selection. Set `OPENAI_API_KEY` and choose the `openai` media provider; an unconfigured Roder installation still defaults to the deterministic offline `fake` provider.

The [media generation guide](/docs/media-generation/) includes configuration, editing inputs and quality options. Image models live in the media catalog, separate from chat model selection.
