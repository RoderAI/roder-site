## Cancel the whole tool command

On Unix, a timed-out or cancelled `shell` command now kills its process group. Timed-out `exec_command` sessions receive the same group cleanup. Because tool children run in their own session, killing only the parent shell could previously leave its work running in the background.

A command that finishes normally leaves its background processes alone. If those processes keep output pipes open, the command is still waiting, so its timeout still applies. This preserves intentional background work while making cancellation and time limits more useful.

## Private tmux restart handoff

Roder still preserves the launching shell's environment when it respawns inside tmux, but now passes it through an owner-only `0600` file. A small shell wrapper sources and deletes the file. Values are no longer placed in `respawn-pane -e` arguments visible in the process list, and non-UTF-8 values survive the transfer.

A failed respawn also no longer prevents the TUI from starting. No new configuration is required: launch Roder from the shell whose environment you want it to use.
