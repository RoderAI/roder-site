## Keep prompts until admission succeeds

Queued and steered prompts stay available until Roder knows whether they were admitted. You can retry rejected input without clearing later follow-ups, or explicitly discard it with `/retry discard`. A failed admission no longer means reconstructing the prompt yourself.

## Preserve history when compaction fails

Explicit and automatic compaction commit a new history boundary only after successful completion. A failure or interruption preserves the original context for retry. Streamed output, subsequent messages and eager tool results remain present exactly once across replay and restart. Usage already reported by the provider still counts even when compaction fails.

Custom Responses-compatible providers can opt into native V2 remote compaction and cap hosted search at cached results through typed capabilities. Omitting those settings preserves existing defaults. See [provider configuration](/docs/providers/).

## Isolate delegated coding work

Coding agents can use `workspace_isolation: "worktree"` to work in durable, Roder-owned Git worktrees. Cleanup is explicit and conservative. See [workspace forks](/docs/workspace-forks/) and [agent control](/docs/agent-control/) before choosing isolation for a task.

The runtime also schedules independent reads around exclusive mutations while retaining approval checks, authentication and remote workspace boundaries.

## Copy source text and preview images

`/copy` navigates original responses and code blocks, preserving source whitespace rather than terminal wrapping. Supported terminals can preview local attached, viewed and generated images with bounded Kitty or Sixel rendering; other terminals retain text fallbacks. See the [terminal interface](/docs/tui/).

## Rust API compatibility change

Command-line use remains supported, but Rust integrators must update `ToolExecutor` implementations to `execution_mode` and initialize the new public configuration and ownership fields. The runtime API now uses explicit shared-read, exclusive and coordinator scheduling, typed custom-provider capabilities and owned worktree metadata.

The shared API's reverse dependency closure is released together to prevent older consumers resolving incompatible public types through patch-compatible packages. The CLI also exports a Rust library, so it participates in this 0.4.0 compatibility boundary.
