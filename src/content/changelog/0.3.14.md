## Continue a thread with another provider

Switching from SuperGrok to OpenAI or Codex now handles oversized history identifiers and incompatible reasoning fields. The saved conversation can be replayed in the destination provider's supported shape instead of failing because it contains source-provider metadata that the new endpoint rejects.

Model selection also avoids loading the full conversation history. In a long thread, choosing a model no longer needs that unnecessary history load before the selection can complete.

## Recover a rejected follow-up

When a follow-up request is rejected, the TUI now shows the failure instead of leaving the user without feedback. Failed input is retained for `/retry`, so you can resolve the cause and resend the request without reconstructing the prompt.

Use the normal model picker to switch models and `/retry` after a failed submission. No thread migration is required. The improvement is in replay compatibility, selection responsiveness and making a failed request both visible and recoverable.
