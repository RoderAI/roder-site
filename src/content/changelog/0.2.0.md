## More consistent Responses and patch behavior

Roder 0.2 packages the Responses agent-loop and Codex patch-parity improvements together. For everyday CLI use, the main workflow stays the same: open a project, give the agent a task and review its edits. The update brings the runtime and its dependent packages onto the same shared API versions.

## Check custom patch callers

`apply_patch` now accepts only the canonical patch argument and Codex patch syntax. Custom tools, scripts or integrations that construct patch calls should send that supported format rather than relying on alternate argument shapes. This makes the edit contract explicit across clients and the runtime.

Rust consumers must rebuild against the updated shared APIs. The release also isolates configuration-dependent tests from saved authentication and process environment, and updates shell coverage to the current Plan-mode process policy. These validation changes help keep local credentials and developer settings from changing test outcomes.
