## Work with real application pages

Jev now waits for pages to settle before choosing an action. It can reach scrollable offscreen controls, nested scrolling regions, open shadow roots and same-origin frames. Repeated labels carry row, card or section context, making it easier to choose the right item in a table or list. Closed shadow roots and cross-origin frame controls remain outside its reach.

Typing handles late focus, suggestions, native dates and times, and formatted fields more carefully. Clicks wait for the target to remain under the pointer and refuse covered controls rather than pressing through an overlay. Dialogs are handled and recorded instead of silently stalling a run.

## Understand partial progress

Timeouts cover setup, page load and the task itself. Runs distinguish missing input, unavailable services, exhausted budgets and timeouts, with a suggested next step. Transient requests have bounded retries that respect the deadline; recorded usage includes billed answers that could not be used, while missing counts remain unknown.

Cookie banners are refused by default when a supported rejection is available. Secret fields are never read back, and values typed into them are scrubbed from later observations. An optional irreversible-action gate can stop a commitment for confirmation. Avoid putting credentials in a goal: use a host-owned value resolver for secrets.

## Configuration and integration changes

Use `JEV_CDP_URL` for an existing CDP endpoint; the old `BU_CDP_URL` and `BU_CDP_WS` variables are not supported. Chrome launched by Roder chooses a debugging port and advertises it in its profile. A stored Codex sign-in can supply the default GPT-6 Sol text helper; explicit model and reasoning settings are validated rather than silently substituted.

Rust integrations need the updated Jev result, action, status and browser APIs. The expanded result includes observed effects, usage and explicit stop reasons, which callers should handle as partial outcomes rather than assuming every return means success.
