## What changed

Roder 0.1.16 adds a native `deepseek` inference provider for DeepSeek Platform. It uses DeepSeek's OpenAI-compatible Chat Completions endpoint at `https://api.deepseek.com/v1`, resolves credentials from `DEEPSEEK_API_KEY`, `RODER_DEEPSEEK_API_KEY`, or `[providers.deepseek]` config, and appears in the same provider catalog as the rest of Roder's first-party model backends.

The built-in catalog includes `deepseek-chat`, `deepseek-reasoner`, `deepseek-v4-flash`, and `deepseek-v4-pro`. The chat and flash routes use non-thinking defaults for everyday coding work, while the reasoner and pro routes expose Roder's normal reasoning controls for longer thinking-heavy turns.

## Why it matters

- DeepSeek Platform no longer has to be wired as a generic custom OpenAI-compatible provider. You can select `deepseek` directly in the CLI, TUI, desktop provider picker, app-server clients, and config files.
- The model list is explicit and discoverable. Users do not have to remember endpoint aliases or copy model ids from an external page before starting a Roder run.
- Provider setup follows the same pattern as other API-key providers, so scripted runs and local interactive sessions can share one credential source.
- Tool calling and structured output support are advertised through Roder's normal catalog metadata, which keeps provider switching predictable for agent workflows.

## Using it

Set a DeepSeek Platform API key, then select the provider and model:

```sh
export DEEPSEEK_API_KEY="..."
RODER_PROVIDER=deepseek RODER_MODEL=deepseek-chat roder
RODER_PROVIDER=deepseek RODER_MODEL=deepseek-reasoner RODER_REASONING=medium roder
```

For persistent defaults, place the same selection in `~/.roder/config.toml`:

```toml
provider = "deepseek"
model = "deepseek-chat"

[providers.deepseek]
api_key = "..."
```

Use `deepseek-chat` for lower-friction coding turns, `deepseek-reasoner` when the task benefits from reasoning budget, and the `deepseek-v4-flash` / `deepseek-v4-pro` routes when your DeepSeek account has access to those models.
