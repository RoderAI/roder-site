## Bind before starting a turn

A hosted external-tool thread now requires an executor binding before it can run. Execution requests go only to that authenticated connection, and results must match the current lease and turn. Disconnecting, unbinding or taking over the executor terminates pending requests.

For hosts that run tools outside the Roder process, this gives ownership a concrete boundary: another connection cannot accidentally answer a request from an old executor. Metadata readback helps a reconnecting host inspect recovery state without automatically replaying effects.

## Update custom clients

The TypeScript SDK provides a generic executor helper with cancellation and duplicate-request suppression for applications that already own their notification loop. Custom transports must expose a synchronous `closedSignal`, allowing executor callbacks to abort as soon as transport loss is known. The unused local `startupTimeoutMs` option is removed.

This is a breaking protocol and shared-type release. Update dependent runtime and client packages together, bind the executor before admitting a turn, and retain application-level reconciliation for external effects whose outcome is uncertain after a disconnect.
