## More dependable long-running goals

Roder corrects goal lifecycle transitions, budgets and usage accounting, and preserves the context needed when autonomous work continues. Fork snapshots carry the corresponding goal state, making continuation more consistent when work branches from an existing session.

These fixes matter when a goal spans several turns: budget reporting and lifecycle state should describe the work actually performed, and a continuation should have the context it needs to keep pursuing the same task.

## Permissions remain part of the goal

Goals now follow the selected permission mode. Full Access automatically permits ordinary approval requests, while explicit denials and restricted child permissions remain in force. Choosing a goal does not erase those restrictions.

Use the existing goal workflow with the permission mode appropriate to the session. No new goal syntax is required by this release; the change is in how the runtime maintains and applies the existing contract.
