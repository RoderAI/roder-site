## Understand the page around a control

Browser results now include a bounded semantic DOM tree with hierarchy, roles, control state and observed node references. This gives the caller more context for controls that look alike or belong to a particular form or workflow. Secret fields and typed secret echoes remain redacted.

The CLI packages the new browser evidence and opt-in decision profiles. Jev's default remains the Workflow prompt. Set `JEV_PROMPT_PROFILE=dom` to try DOM-grounded Jev decisions, and `JEV_IMAGES=1` to include fitted viewport images. Candidate rectangles are scaled with the screenshot so their visual references stay aligned. The experimental `dom_targets` and `activation` profiles add selective image routing and pending-action completion checks.

## Add DOM evidence to native Decisions

For an already configured Chrome and text-helper environment:

```sh
export JEV_DECISION_PROVIDER=openai
export JEV_DECISIONS_PROFILE=dom
roder
```

Supply `OPENAI_API_KEY` through your normal credential setup. Decisions requires an API key; Codex sign-in alone does not authenticate it. The default Decisions profile remains `vision`. `dom` adds semantic structure and form/workflow questions, while experimental `activation` adds clipped-field image routing and typed completion audits.

DOM Decisions retains safe viewport screenshots. `JEV_DECISIONS_TEXT_ONLY=1` keeps the selected profile but disables image transmission. Recognized secret fields and remembered typed secrets suppress screenshots, and optional capture failures can fall back to text. These protections are not general sensitive-image detection.

## Measure completion and cost honestly

Component decisions and audits share the remaining browser budget and contribute to reported calls and usage, including billed-error paths. Existing approval and irreversible-action gates still apply. Profiles are opt-in: use the default when you do not need the extra evidence or audit calls. See the [browser decisions guide](/docs/browser-decisions/) for configuration and outcome checks.
